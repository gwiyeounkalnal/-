밀당금지 - Render 무료 배포 안내

1. GitHub에 올리기
- 이 폴더(door-watch) 안의 파일을 GitHub 저장소 최상위에 업로드합니다.
- node_modules 폴더는 올리지 않습니다.

2. Render 배포
- https://render.com 에 가입/로그인합니다.
- New + > Blueprint를 선택하고 GitHub 저장소를 연결합니다.
- 저장소의 render.yaml을 읽어 서비스 설정을 불러옵니다.
- 환경 변수 PASSWORD를 설정하라는 안내가 나오면 추측하기 어려운 접속 비밀번호를 입력합니다.
- Apply를 눌러 배포합니다.

3. 접속
- 배포가 끝나면 Render가 제공하는 https://서비스이름.onrender.com 주소를 엽니다.
- 접속 비밀번호를 입력한 뒤 카메라 권한을 허용합니다.
- 처음 사용할 때 당기기 학습과 밀기 학습을 각각 진행합니다.

중요한 제한
- Render 무료 웹 서비스는 15분 동안 요청이 없으면 절전되고, 다시 접속할 때 깨어나는 데 약 1분 걸릴 수 있습니다.
- 무료 서비스의 로컬 파일은 재배포, 재시작, 절전 시 사라질 수 있습니다. 이 프로젝트의 횟수/기록/사진은 records 폴더에 저장되므로 무료 Render에서는 영구 보존되지 않습니다.
- 중요한 기록을 보존하려면 데이터베이스/외부 파일 저장소를 별도로 연결해야 합니다.
- 무료 Render Postgres는 30일 후 만료되는 제한이 있으므로 장기 보관용으로 그대로 사용하면 안 됩니다.

개인정보 및 보안
- 이 앱은 이벤트 당시 카메라 화면을 사진으로 저장할 수 있습니다. 카메라는 문만 보이도록 설치하고, 사람 얼굴이나 학생 개인 정보가 촬영·저장되지 않도록 학교의 허가와 안내를 먼저 확인하세요.
- PASSWORD 환경 변수를 반드시 설정하고 접속 비밀번호를 공개 게시물에 올리지 마세요.
- GitHub 저장소에는 실제 기록, 사진, 비밀번호를 올리지 마세요. .gitignore가 기록 파일을 제외하도록 설정되어 있습니다.

로컬 실행
- Node.js 18 이상 설치
- 터미널에서 이 폴더로 이동
- npm install
- npm start
- 브라우저에서 https://localhost:3000 접속 (개발용 자체 인증서 경고가 표시될 수 있음)
